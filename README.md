# Material Educativo de Ofimática - Grado Sexto (6°)

Aplicación web interactiva e imprimible diseñada para la enseñanza y evaluación de conceptos fundamentales de **Ofimática** en el área de **Tecnología e Informática** para estudiantes de **Grado 6°**.

## 📚 Contenido Pedagógico

### 1. 10 Preguntas de Verdadero o Falso
- Origen del término ofimática (Oficina + Informática).
- Diferencias entre procesador de texto y hoja de cálculo.
- Estructura de filas (números) y columnas (letras) en hojas de cálculo.
- Atajos de teclado clave (`Ctrl + Z`, `Ctrl + C`, `Ctrl + V`, `Ctrl + G`).
- Concepto de diapositivas en presentaciones multimedia.
- Almacenamiento organizado por carpetas vs. desorden en el escritorio.
- Ventajas del formato PDF para entrega de trabajos escolares.
- Ergonomía y postura adecuada frente al computador.

### 2. 5 Preguntas de Selección Múltiple (A, B, C, D)
- **Pregunta 11:** Selección del software adecuado para redacción escolar (Word / Docs).
- **Pregunta 12:** Identificación de celdas por coordenadas (ej. Celda C7).
- **Pregunta 13:** Software de apoyo visual para exposiciones (PowerPoint / Slides).
- **Pregunta 14:** Carácter obligatorio para iniciar fórmulas (`=`).
- **Pregunta 15:** Atajo para seleccionar todo el documento (`Ctrl + E` / `Ctrl + A`).

### 3. Módulos y Funcionalidades
- **Taller Interactivo:** Evaluación en tiempo real con escala valorativa escolar (1.0 a 5.0) y desempeño según Decreto 1290 (Superior, Alto, Básico, Bajo).
- **Simulador de Hoja de Cálculo:** Laboratorio visual para interactuar con columnas, filas, celdas y la barra de fórmulas.
- **Laboratorio de Atajos de Teclado:** Simulador interactivo en vivo con portapapeles y función deshacer.
- **Centro de Impresión Docente:**
  - Formato de examen listo para fotocopiar con membrete institucional editable.
  - Hoja de respuestas en formato de óvalos.
  - Solucionario con justificación pedagógica y estándares curriculares del MEN.
  - Exportación con un clic para Microsoft Word o Google Forms.

## 🚀 Tecnologías Utilizadas

- Tailwind CSS
- Lucide React
- Canvas Confetti
